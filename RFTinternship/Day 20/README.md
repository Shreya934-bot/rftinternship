# 📊 Day 20 – Sales Analytics Capstone Project

## Overview

This capstone project performs complete sales data analysis using Python.

The project follows a complete data analytics workflow:

- Data Cleaning
- Data Analysis
- Data Visualization
- Insight Generation

---

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn

---

## Features

✅ Data Cleaning

✅ Revenue Analysis

✅ Product-wise Sales Analysis

✅ Region-wise Sales Analysis

✅ Sales Trend Visualization

✅ Business Insights Generation

---

## Visualizations

### Sales Trend
Line chart showing revenue trend over time.

### Product Sales
Bar chart comparing revenue generated by products.

### Region-wise Sales
Pie chart showing contribution of each region.

---

## Key Insights

- Laptop is the highest revenue-generating product.
- South region shows strong performance.
- Sales trend indicates steady growth.
- Product demand differs by region.
- Useful for business decision-making.
