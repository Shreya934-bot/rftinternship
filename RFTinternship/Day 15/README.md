# 📊 Day 15 – Mini EDA Dashboard

## 📌 Overview
This project builds a mini Exploratory Data Analysis (EDA) dashboard using Python, Matplotlib, and Seaborn.

The dashboard combines:
- line charts
- bar charts
- histograms

to generate insights and understand trends in data.

---

## 🚀 Features
- ✅ Line chart for sales trend
- ✅ Bar chart for customer comparison
- ✅ Histogram with KDE curve
- ✅ Multiple plots using subplots
- ✅ Basic insight generation
- ✅ Outlier detection using IQR method

---

## 🧠 Concepts Practiced
- Exploratory Data Analysis (EDA)
- Multiple Visualizations
- Subplots
- Trend Analysis
- Distribution Analysis
- Insight Generation
- Outlier Detection

---

## 📂 Dataset

```python
data = {
    "Day": ["Mon", "Tue", "Wed", "Thu", "Fri"],
    "Sales": [200, 250, 300, 280, 350],

}
```
