
# 📊 Day 23 – Employee Performance Analytics System

## 📌 Overview

This project focuses on analyzing employee performance and attendance data using Python.

The project performs data analysis, generates visualizations, identifies high-performing employees, detects employees with low attendance, and exports the final analytical report as a CSV file.

An interactive **Streamlit dashboard** was also developed as a bonus challenge to allow users to explore employee performance data using filters.

---

## 🎯 Objectives

The main objectives of this project are:

- Import employee performance data from a CSV file
- Clean and preprocess the dataset
- Calculate department-wise average performance
- Identify the Top 10 performing employees
- Find employees with attendance below 75%
- Analyze department distribution
- Visualize employee performance and attendance
- Export the final employee report as a CSV file
- Build an interactive Streamlit dashboard

## 🔍 Analysis Performed

### 1. 🧹 Data Cleaning

The employee dataset was cleaned and prepared for analysis.

The process includes:

* Checking missing values
* Handling duplicate records
* Validating data
* Preparing numerical columns for analysis

---

### 2. 📊 Department-wise Average Performance

Employee performance was grouped according to department to calculate the average performance score for each department.

This helps compare the overall performance of different departments.

---

### 3. 🏆 Top 10 Performers

Employees were sorted according to their performance scores to identify the **Top 10 highest-performing employees**.

This provides a quick overview of the organization's strongest performers.

---

### 4. ⚠️ Low Attendance Analysis

Employees with attendance below **75%** were identified.

This analysis can help organizations detect attendance-related issues and identify employees who may require additional attention.

## 🖥️ Streamlit Dashboard

As a bonus challenge, an interactive dashboard was developed using **Streamlit**.

The dashboard allows users to:

* View employee performance data
* Filter employees
* Analyze department performance
* View Top 10 performers
* Identify employees with attendance below 75%
* Download a filtered employee report

### Run the Dashboard

Install the required libraries:

```bash
pip install pandas matplotlib streamlit
```

Run the Streamlit application:

```bash
streamlit run streamlit_dashboard.py
```

The dashboard will open in the browser at the local Streamlit address.
