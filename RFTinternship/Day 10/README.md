# 📊 Day 10 – Simple Log Analyzer

## 📌 Overview
This project analyzes system log messages using Python.

The program identifies and counts different types of logs such as:
- ERROR
- INFO
- WARNING

It also determines the most frequent log category.

---

## 🚀 Features
- ✅ Analyze system log messages
- ✅ Count ERROR, INFO, and WARNING logs
- ✅ Ignore case sensitivity
- ✅ Detect most frequent log type
- ✅ Display total logs analyzed

---

## 🧠 Concepts Practiced
- String Processing
- Pattern Detection
- Conditional Logic
- Counting Techniques
- Lists & Dictionaries
