# 📊 Day 7 – Student Performance Dashboard

## 📌 Overview
This project analyzes student academic performance using Python and CSV data processing.

The program calculates:
- average marks
- grades
- topper information
- subject-wise averages
- students performing above average

It simulates the logic behind a simple academic performance dashboard.

---

## 🚀 Features
- ✅ Read student data from CSV file
- ✅ Calculate average marks per student
- ✅ Add grade column
- ✅ Find class topper
- ✅ Count students above average
- ✅ Compute subject-wise averages

---

## 🧠 Concepts Practiced
- File Handling
- Data Aggregation
- Row vs Column Operations
- Conditional Logic
- Lists & Dictionaries
- Basic Dashboard Thinking
