# 🎬 Day 18 – Movie Dataset Analysis

## 📌 Overview
This project performs exploratory analysis on a movie dataset using Python, Pandas, Matplotlib, and Seaborn.

The analysis focuses on:
- movie ratings
- genre-wise revenue
- trend analysis
- correlation analysis
- visualization and insight generation

This simulates a beginner-level entertainment analytics workflow.
