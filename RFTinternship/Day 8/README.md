# 📊 Day 8 – Employee Salary Insights

## 📌 Overview
This project analyzes employee salary data using Python and CSV processing techniques.

The program groups employees by department and performs salary-based aggregation and analysis.

It demonstrates the core concept of **GROUPBY**, which is widely used in:
- Data Analysis
- Pandas
- SQL
- Business Analytics

---

## 🚀 Features
- ✅ Read employee data from CSV file
- ✅ Group employees by department
- ✅ Calculate average salary per department
- ✅ Find highest-paid employee in each department
- ✅ Count employees department-wise
- ✅ Sort departments by average salary

---

## 🧠 Concepts Practiced
- File Handling
- CSV Processing
- GROUPBY Logic
- Aggregation
- Dictionaries & Lists
- Sorting Techniques
