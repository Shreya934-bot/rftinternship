# Day 21 — Functions: Intermediate

## 📌 Internship

**Python Developer Internship — GOW AI Academy**

## 🎯 Objective

The objective of Day 21 is to practice intermediate-level Python functions and understand how different types of function arguments and return values work.

## 📚 Concepts Covered

* Function parameters
* Default parameters
* `*args`
* `**kwargs`
* Return values
* Scope of variables

## 📝 Tasks Completed

### 1. Prime Number Checker

Created a function `is_prime()` that checks whether a given number is a prime number.

### 2. Largest Number Using `*args`

Created a function `find_largest()` that accepts any number of numerical arguments using `*args` and returns the largest value.

### 3. Student Information Using `**kwargs`

Created a function `student_information()` that accepts student details using `**kwargs` and displays them in a readable format.

### 4. Statistics Challenge

Created a function `calculate_statistics()` that accepts a list of numbers and calculates:

* Maximum
* Minimum
* Average
* Sum
