# 📊 Day 4 – Simple Log Analyzer

## 📌 Overview
This project analyzes system log messages using Python string processing and counting techniques.

The program detects and counts different types of logs such as:
- ERROR
- INFO
- WARNING

It also identifies the most frequent log category.

---

## 🚀 Features
- ✅ Count ERROR logs
- ✅ Count INFO logs
- ✅ Count WARNING logs
- ✅ Detect most frequent log type
- ✅ Ignore case sensitivity
- ✅ Basic pattern detection

---

## 🧠 Concepts Practiced
- String Processing
- Pattern Matching
- Dictionaries
- Counting Logic
- Lists & Loops
