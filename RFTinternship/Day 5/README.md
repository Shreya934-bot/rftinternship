# 📄 Day 5 – Basic CSV Reader (Without Pandas)

## 📌 Overview
This project demonstrates how to read and process CSV files using pure Python without using the Pandas library.

The program reads student data from a CSV file, structures it into dictionaries, and performs basic analysis.

---

## 🚀 Features
- ✅ Read CSV file using file handling
- ✅ Split and process string data
- ✅ Store records as list of dictionaries
- ✅ Handle missing values
- ✅ Calculate average marks
- ✅ Display structured student records

---

## 🧠 Concepts Practiced
- File Handling
- String Splitting
- Data Structuring
- Lists & Dictionaries
- Basic Data Analysis
