## Day 2 – Student Score Analyzer

## Problem Statement

Analyze a list of student marks and extract meaningful insights such as average score, highest & lowest marks, and grade distribution.

##  Given Data

```
marks = [78, 85, 90, 67, 85, 92, 78]
```

##  Features

* Calculate average marks
* Find highest and lowest scores
* Count students scoring above average
* Generate grade distribution (A/B/C/Fail)

## Concepts Used

* Lists
* Functions
* Basic Statistics
* Conditional Logic

## Output Example

```
Average: 82.14
Highest: 92
Lowest: 67
Students above average: 3
Grade Distribution: {'A': 2, 'B': 3, 'C': 2, 'Fail': 0}
```

##  Learning Outcome

This task helped in converting raw numerical data into meaningful insights using Python.
