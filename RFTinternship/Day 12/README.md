# 📊 Day 12 – Student Performance Dashboard

## 📌 Overview
This project visualizes student performance data using Python and Matplotlib.

The program creates:
- bar charts for marks comparison
- grouped bar charts for multiple subjects
- visual comparisons between students

It demonstrates how dashboards and comparative analytics are built using data visualization techniques.

---

## 🚀 Features
- ✅ Create bar chart using Matplotlib
- ✅ Compare student marks visually
- ✅ Add labels and chart title
- ✅ Generate grouped bar chart
- ✅ Compare multiple subjects

---

## 🧠 Concepts Practiced
- Data Visualization
- Bar Charts
- Comparative Analysis
- Grouped Bar Charts
- Plot Labeling
- Dashboard Thinking
