# 🔐 Fraud Detection & Transaction Analysis System

## 📌 Day 25 – RFT Python Internship

### 🎯 Task Overview

The task for Day 25 was to build a **Fraud Detection & Transaction Analysis System** using Python.

The objective was to analyze transaction data, identify potentially suspicious activities, generate visualizations, and export suspicious transactions for further investigation.

---

## 💡 Tasks Completed

### 📂 Data Processing

- Read transaction data from a CSV file
- Processed and analyzed transaction records using Pandas
- Converted transaction dates for time-based analysis
- Checked the dataset for duplicate transactions

---

### 🔁 Duplicate Transaction Detection

Duplicate transaction patterns were identified to help detect potentially suspicious or repeated transaction activity.

---

### 💰 High-Value Transaction Detection

Transactions above a specified threshold were identified as high-value transactions for further analysis.

---

### 👤 Suspicious Account Detection

Accounts with frequent transactions were analyzed to identify potentially suspicious account activity.

---

## 📊 Visualizations Generated

The project generates the following visualizations:

### 1. 📊 Transaction Category Chart

Displays the distribution of transactions across different transaction categories.

### 2. 📈 Daily Transaction Trend

Shows how transaction activity changes over time.

### 3. 💰 Top 10 Highest Transactions

Identifies and visualizes the top 10 transactions with the highest transaction amounts.

---

## 🚨 Suspicious Transaction Report

Suspicious transactions are identified based on the analysis and exported into a separate CSV file.

This report can be used for further investigation and analysis.

---

## ⭐ Bonus Challenge

### 🧠 Transaction Risk Score

A risk score was created for each transaction based on multiple transaction-related factors.

Transactions are categorized into different risk levels to help prioritize potentially suspicious activity.

The analysis considers factors such as:

- High transaction amounts
- Duplicate transaction patterns
- Frequent account activity
- Transaction status

---

### 🖥️ Streamlit Dashboard

An interactive Streamlit dashboard was also developed for exploring the transaction data.

The dashboard includes:

- Transaction overview metrics
- Transaction category analysis
- Risk-level analysis
- Suspicious transaction investigation
- Account-level analysis
- Daily transaction trends
- City and payment method analysis
- Search functionality
- Interactive filters
- CSV report download
