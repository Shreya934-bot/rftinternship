# 📊 Day 6 – Sales Data Analyzer

## 📌 Overview
This project analyzes sales data from a CSV file using pure Python.

The program performs:
- revenue calculation
- product-wise aggregation
- sorting operations
- column-based analysis

without using external libraries like Pandas.

---

## 🚀 Features
- ✅ Read CSV sales data
- ✅ Add calculated TOTAL column
- ✅ Calculate total revenue
- ✅ Compute sales per product
- ✅ Identify top-selling product
- ✅ Sort products by revenue

---

## 🧠 Concepts Practiced
- File Handling
- CSV Reading
- Column Operations
- Aggregation Logic
- Dictionaries & Lists
- Sorting Techniques
