# 📊 Day 22 – Sales & Customer Insights Dashboard

## Overview

This project focuses on performing sales and customer analysis using Python and a CSV dataset.

The project follows a complete data analysis workflow:

* Data Cleaning
* Sales Analysis
* Customer Analysis
* Product Analysis
* Category Analysis
* Data Visualization
* Business Insight Generation

---

## Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook

---

## Features

✅ Missing Data Handling

✅ Duplicate Data Removal

✅ Total Sales Calculation

✅ Average Revenue Calculation

✅ Top 5 Customer Identification

✅ Top Product Analysis

✅ Category-wise Revenue Analysis

✅ Sales Trend Visualization

✅ Business Insights Generation

---

## Data Cleaning

The dataset was checked and cleaned by:

* Identifying missing values
* Removing duplicate records
* Filling missing customer and category values
* Handling missing revenue values
* Converting the Date column into the appropriate datetime format

---

## Analysis Performed

### 💰 Total Sales

Calculated the total revenue generated from all sales transactions.

### 📈 Average Revenue

Calculated the average revenue generated per transaction.

### 👥 Top 5 Customers

Identified the five customers contributing the highest total revenue.

### 🛍️ Top Products

Analyzed product-wise revenue and identified the highest-performing products.

### 📦 Category Distribution

Analyzed revenue contribution across different product categories.

---

## Visualizations

### 📈 Sales Trend

A line chart showing how sales revenue changes over time.

### 📊 Top Products

A bar chart comparing the revenue generated by the top-performing products.

### 🥧 Category Distribution

A pie chart showing the percentage contribution of each product category to total revenue.

---

## Business Insights

The analysis generates five business insights based on:

* Highest-value customer
* Best-performing product
* Leading product category
* Highest sales day
* Average transaction revenue

These insights can help businesses understand customer value, product performance, category contribution, and sales patterns.

## ▶️ How to Run

1. Install the required Python libraries:

```bash
pip install pandas matplotlib seaborn
```

2. Keep the CSV dataset in the same folder as the Python file.

3. Run the Python program:

```bash
python sales_customer_insights.py
```

4. The program will generate the required charts:

```text
sales_trend.png
top_products.png
category_distribution.png
```
