# 📞 Day 3 – Dictionary-Based Phonebook

## 📌 Overview

This project is a simple dictionary-based phonebook application built using Python.

It demonstrates the use of:

* Dictionaries
* CRUD operations
* Functions
* Loops & conditional statements

* ➕ Add Contact

* 🗑️ Delete Contact
* 📖 Display All Contacts
