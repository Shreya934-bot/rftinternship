# 📊 Day 13 – Distribution Analysis using Seaborn

## 📌 Overview
This project analyzes data distribution using Python, Seaborn, and Matplotlib.

The program visualizes the distribution of student marks using:
- Histogram
- KDE Curve (Kernel Density Estimation)

It also identifies the skewness of the dataset.

---

## 🚀 Features
- ✅ Create histogram using Seaborn
- ✅ Add KDE curve
- ✅ Analyze data distribution
- ✅ Identify skewness
- ✅ Save visualization as image

---

## 🧠 Concepts Practiced
- Data Visualization
- Histograms
- KDE Curves
- Distribution Analysis
- Statistical Thinking
- Exploratory Data Analysis (EDA)

## 📂 Dataset

```python
marks = [55, 60, 65, 70, 72, 75, 78, 80,
         82, 85, 87, 90, 92, 95, 97, 100]
```
