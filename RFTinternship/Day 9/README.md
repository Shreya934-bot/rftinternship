# 📊 Day 9 – Data Filtering Tool

## 📌 Overview
This project filters employee data using Python and CSV processing techniques.

The program applies multiple conditions to filter records and displays only matching results.

It also saves the filtered output into a new CSV file.

---

## 🚀 Features
- ✅ Read employee dataset from CSV
- ✅ Apply boolean filtering conditions
- ✅ Combine multiple conditions
- ✅ Display filtered records
- ✅ Save filtered data into a new CSV file

---

## 🧠 Concepts Practiced
- File Handling
- Boolean Filtering
- Conditional Logic
- CSV Processing
- Data Structuring
- Filtering Operations
